# Estudo Individual Java

Repositório para registrar estudos práticos de Java, organizados por assunto.

## Estrutura

- `01-fundamentos`: variáveis, tipos, operadores, condicionais e laços.
- `02-poo`: classes, objetos, encapsulamento, herança e polimorfismo.

## Como executar

Com um JDK instalado:

```powershell
javac src/main/java/br/com/victor/estudos/fundamentos/HelloJava.java
java -cp src/main/java br.com.victor.estudos.fundamentos.HelloJava
```
